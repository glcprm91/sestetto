# Logo di Sestetto

- `simbolo.svg`: il simbolo, usato anche come favicon. Sei giocatori che ruotano in senso orario attorno al campo, sotto la rete; il pallino giallo è il palleggiatore in posto 1.
- `simbolo-16px.svg`: versione semplificata per le dimensioni piccolissime (favicon a 16 px).
- `logo-chiaro.*`: simbolo e scritta, per sfondi scuri.
- `logo-scuro.*`: simbolo e scritta, per sfondi chiari.

La scritta è in Archivo (larghezza 68, peso 800), convertita in tracciati: non serve avere il carattere installato.

Colori: blu campo `#1F5FA9`, bianco `#F4F7FB`, giallo `#F5C518`, blu notte `#0F1B31`.
